## Development caveats and publication status

Memory selection is best-effort budget policy, not a hard RSS cap or availability
guarantee. It does not account for competing physical-RAM users, hidden cgroup
ancestors, RLIMIT_AS, Windows Job Objects, or macOS container limits. Linux
missing/unreadable visible cgroup data can cause the conservative fallback seen
in these actual smoke/acceptance records.
