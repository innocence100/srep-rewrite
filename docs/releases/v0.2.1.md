## What this release is

SREP-NG 0.2.1 carries the accepted sparse-input m3 optimization: end-order fusion
during pass 2, compact authenticated candidate/DP rows, and a bounded optional
predecessor directory. It does not change the NGv3 wire format or the matching
semantics. The software version is 0.2.1 and the wire-format version is NGv3.

- NGv3 is read/write and self-contained.
- Historical SuperREP v1–v4 are embedded read-only inputs.
- NGv1 and NGv2 are rejected as `UnsupportedVersion`.
- Split indexes and sidecar indexes are rejected/unsupported.
- Compression defaults to m3 / index / xxh3 / 8 MiB blocks.
- Rust 1.88.0 remains the MSRV; the package remains MIT-licensed, with dependency
  attribution governed by the lockfile audit and package notices.
- Preserve the original input, test the archive, decompress to a new
  destination, and compare bytes before deleting or replacing source data.

The optimization was source-reviewed and its prior native/CI validation passed on
source/tooling commit `4af679fd4292c3f864db1eb717e48f504e58e78a`; the final
evidence review was accepted (R-P4 PASS). The 0.2.1 production source and
algorithm tests are unchanged from that accepted source; the sole test change is
the `tests/release_cli.rs` package-version assertion updated from 0.2.0 to
0.2.1.
