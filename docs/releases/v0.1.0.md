# SREP-NG 0.1.0 release notes

**Status: limited 0.1.0 preview documentation.** Source and Linux candidate
checks for this preview are complete. A GitHub Release is a later integrator
step and is not implied by this file.

SREP-NG 0.1.0 is an explicitly limited preview of the current **SREP-NG v3
(NGv3)** software and archive format. The product version is 0.1.0; NGv3 is
the wire-format version. NGv3 is the format written and read by this release.

## Scope and compatibility

- NGv3 archives are self-contained `.srep` files and support the m0–m5
  methods and Index-LZ, Future-LZ, and I/O-LZ layouts.
- Historical SuperREP v1–v4 embedded archives are read-only. They may be
  inspected or used as migration inputs; this project does not write them.
- NGv1 and retired NGv2 are rejected as `UnsupportedVersion`. No NGv1/NGv2
  writer, reader, conversion path, or unsupported compatibility promise is
  part of this release.
- Split indexes and sidecar indexes are unsupported.
- The default method is m3 with the documented default block size of 8 MiB.
  Large or repetitive inputs may need substantial RAM and temporary disk.

This is a preview, not a claim of historical compressor parity. The release
does not promise a compression ratio, runtime, byte-for-byte output, or
compatibility outside the policy above.

## Linux package

The mandatory package is:

```text
srep-v0.1.0-x86_64-unknown-linux-gnu.tar.gz
```

It is a Linux x86_64 glibc package. The tarball's archive root has the same
basename and contains exactly the release-facing files below:

```text
srep
LICENSE
THIRD_PARTY.md
THIRD_PARTY.audit
README.md
CHANGELOG.md
NOTICES
```

The `SHA256SUMS` file is external to the tarball. A user verifies and runs the
package as follows:

```sh
sha256sum -c SHA256SUMS
tar -xzf srep-v0.1.0-x86_64-unknown-linux-gnu.tar.gz
cd srep-v0.1.0-x86_64-unknown-linux-gnu
./srep --version
./srep --help
```

The Linux x86_64 preview binary is dynamically linked (`libc.so.6`,
`ld-linux-x86-64.so.2`, `libpthread.so.0`, `libgcc_s.so.1`, `libdl.so.2`).
`readelf` observed GNU libc symbol versions up to **GLIBC_2.30**. That is a
runtime symbol-version bound, not a distro package name. Exact source SHA,
compiler, binary SHA-256, and tarball SHA-256 are recorded in package
`NOTICES` and the adjacent `SHA256SUMS` file. Windows and macOS packages are
optional and are not promised by this preview.

## Safe first run

Keep a backup of every original before archiving. Verify the archive and a
round trip before deleting or replacing the source:

```sh
./srep compress input.bin input.bin.srep
./srep test input.bin.srep
./srep decompress input.bin.srep restored.bin
cmp input.bin restored.bin
```

`--version`/`-V`, `--help`, `--seed-size`, and `--target-chunk` are part of the
agreed CLI interface. For large inputs, review `--memory`, `--temp-dir`, and
`--temp-limit`; a limit failure must remain explicit rather than silently
weakening matching.
